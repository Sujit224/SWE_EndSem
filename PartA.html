Introduction

1.1 Purpose & 1.2 Scope

This SRS defines requirements for "SwiftRide," an online cab booking platform covering Passenger, Driver, and Admin modules.

Core Features:
  • Instant & Scheduled Booking
  • Real-time GPS Tracking
  • Secure Payments
  • Dynamic Pricing
System Coverage:
  • Mobile-First Design
  • Scalable Architecture
  • Operational Framework
2
General Description

SwiftRide connects passengers needing rides with drivers via a highly available backend. The system is optimized for:

Minimal Wait Times
Max Driver Earnings
Transparent Pricing
Reliable Safety
3
Functional Requirements
FR-101
User Onboarding
  • Login: Email, OTP, Social.
  • Profile: Payment, Emergency Contacts.
FR-102
Ride Request
  • Map/Manual Pickup.
  • Fare/ETA Estimates.
  • Car Types (SUV, Luxury).
FR-103
GPS & Navigation
  • Real-time Tracking (4-6s).
  • Share Live Trip.
  • Driver Navigation.
FR-104
Payment System
  • Card, UPI, Wallets.
  • Fare Breakdown.
  • Promo Codes.
FR-105
Ratings & Feedback
  • 1-5 Star Ratings.
  • Comments & Issue Reporting.

Design Constraints
  • Compatibility: iOS ≥13, Android ≥6.0, Modern Web Browsers.
  • Security: bcrypt encryption, PCI-DSS for payments, GDPR compliance.
  • Reliability: Cloud hosting, Load balanced servers.
